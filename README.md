# Projecte LMSGI · Quincena 2: FitPlan Generator

## 1. Descripció del Domini
FitPlan Generator és un lloc web que recopila les dades antropomètriques de l'usuari (edat, pes, altura i objectiu) i el seu gimnàs de referència per a mostrar una dieta personalitzada i una rutina d'entrenament basada en les màquines disponibles en eixes instal·lacions.

## 2. Estructura de Navegació
- `index.html`: Formulari d'entrada de dades de l'usuari.
- `catalogo.html`: Catàleg dels gimnasos registrats i el seu equipament.
- `detalle-plan.html`: Vista de la dieta i rutina generades (fitxa de detall).

## 3. Decisions Tècniques
1. **HTML5 Semàntic:** Ús d'etiquetes `<header>`, `<nav>`, `<main>`, `<article>`, `<section>`, `<form>` i `<table>`.
2. **Navegació relativa:** Tots els fitxers estan enllaçats de manera relativa.
3. **Imatges i Accessibilitat:** Descripcions `alt` en les imatges d'equipament.
